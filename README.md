# Molymorph privacy policy

Static privacy-policy website hosted on GitHub Pages.

- [Privacy policy](https://studiomolymorph.github.io/privacy/)
- [Japanese version](https://studiomolymorph.github.io/privacy/#ja)
- [app-ads.txt](https://studiomolymorph.github.io/app-ads.txt)

The policy is available in Japanese, English, Simplified Chinese, Traditional Chinese, Korean, Spanish, Brazilian Portuguese, French, German, and Italian. The Japanese text is the editorial source; other versions are translations. The last update is October 31, 2026.

The localized last-updated date appears in the page footer. No effective date is displayed.

English is shown by default. Language links and URL fragments select another language; browser-language detection is not used. With JavaScript disabled, all language versions remain readable, with English first. The root page redirects to `/privacy/` and preserves the language fragment when JavaScript is enabled.

This repository contains only public website files. Policy content and language labels are generated from the maintained Japanese source and translation files outside this repository. Layout is in `privacy/document.css`, and language switching is in `privacy/document.js`. No custom analytics, advertising tags, external fonts, or submission forms are installed on the website.

GitHub Pages deploys from the `main` branch, `/(root)`. Operator and contact information appears at the end of each policy. Privacy inquiries use `studio.molymorph+privacy@gmail.com`.

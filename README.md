# Molymorph public website

GitHub Pages用の日英プライバシーポリシー。公開する情報だけを置きます。ゲームソース、署名鍵、パスワード、復旧コード、端末の記録は追加しません。

- Root (redirects to the privacy policy): https://studiomolymorph.github.io/
- Privacy policy (Japanese / English): https://studiomolymorph.github.io/privacy/
- English section: https://studiomolymorph.github.io/privacy/#en
- app-ads.txt: https://studiomolymorph.github.io/app-ads.txt

`Settings > Pages`のSourceを`Deploy from a branch`、Branchを`main`、Folderを`/(root)`に設定します。独自ドメインは使用しません。静的HTML/CSSと小さな言語切替用JavaScriptで構成し、独自の広告タグ・解析・外部フォント・フォーム送信はありません。

ポリシーの変更は`privacy/index.html`の日本語と英語の両方へ反映し、更新日も変更します。見た目は`privacy/document.css`、言語切替は`privacy/document.js`で管理します。独立したホーム画面はありません。ルートの`index.html`は`/privacy/`へ転送し、JavaScriptが有効なら言語のハッシュも引き継ぎます。

運営者と問い合わせ先はポリシー末尾に記載します。プライバシーポリシー経由の問い合わせを識別するため、受信先は`studio.molymorph+privacy@gmail.com`です。

app-ads.txtのpublisher IDは本アプリで使用するAdMobアプリIDのpublisher部分です。GoogleのDIRECT販売者行を記載しています。AdMob管理画面のパーソナライズされたコードと一致することを運用時に確認し、ストアのデベロッパーWebサイトにはルートURLを登録します。ファイルを置くだけでAdMobのアプリ審査や同意設定が完了するわけではありません。
